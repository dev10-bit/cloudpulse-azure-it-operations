# CloudPulse – Azure IT Operations Monitoring Platform

CloudPulse is an end-to-end IT monitoring project built on Microsoft Azure.
It collects system health metrics from Windows devices, ingests them via
Azure Functions, stores them in Azure Storage, and visualizes them in a web dashboard.

## Tech Stack
- Azure Functions (Python)
- Azure Storage (Table Storage)
- Azure Static Web Apps
- Azure Logic Apps (alerts)
- PowerShell (device agent)
